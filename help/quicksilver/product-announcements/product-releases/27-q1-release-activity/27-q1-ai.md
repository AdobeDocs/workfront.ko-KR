# 2027년 1분기 AI 개선 사항

이 페이지에서는 미리보기 환경에 대한 2027년 1분기 릴리스의 AI 개선 사항에 대해 설명합니다. 이러한 개선 사항은 언급된 대로 프로덕션 환경에서 사용할 수 있습니다.

2027년 1분기 릴리스 주기에 이 시점에서 사용할 수 있는 모든 변경 사항 목록은 [2027년 1분기 릴리스 개요](/help/quicksilver/product-announcements/product-releases/27-q1-release-activity/27-q1-release-overview.md)를 참조하십시오.

## Workfront MCP 서버 도구 세트

>[!NOTE]
>
>미리 보기: 2026년 10월 21일
>프로덕션 빠른 릴리스: 2026년 11월 12일
>모두를 위한 프로덕션: 2027년 1월 21일

AI 클라이언트가 액세스할 수 있는 Workfront 기능을 보다 쉽게 제어할 수 있도록 Workfront MCP 서버에 도구 세트를 추가했습니다. 이제 전체 승인된 도구 목록을 노출하는 대신 MCP 카탈로그를 클라이언트에 필요한 기능으로 제한할 수 있습니다. 사용 가능한 도구 집합에는 `core`, `comment-stream`, `planning` 및 `approvals`이(가) 있습니다.

이제 도구 가용성도 제품 권한을 보다 명확하게 반영합니다. Workfront Planning에만 사용이 허가된 고객은 Planning 도구를 참조하고, Workfront Workflow에만 사용이 허가된 고객은 Workflow 도구를 참조하고, 두 세트에 모두 사용이 허가된 고객은 두 세트를 참조하십시오.

자세한 내용은 [Adobe Workfront MCP 서버 구성](/help/quicksilver/workfront-basics/workfront-mcp-server/configure-workfront-mcp-server.md) 및 [Adobe Workfront MCP 서버 사용](/help/quicksilver/workfront-basics/workfront-mcp-server/use-workfront-mcp-server.md)을 참조하십시오.
