# 2026년 4분기 AI 개선 사항

이 페이지에서는 미리보기 환경에 대한 2026년 4분기 릴리스의 AI 개선 사항에 대해 설명합니다. 이러한 개선 사항은 언급된 대로 프로덕션 환경에서 사용할 수 있습니다.

2026년 4분기 릴리스 주기에 이 시점에서 사용할 수 있는 모든 변경 사항 목록은 [2026년 4분기 릴리스 개요](/help/quicksilver/product-announcements/product-releases/26-q4-release-activity/26-q4-release-overview.md)를 참조하십시오.

## Workfront에서 CX Coworker 사용 가능

>[!NOTE]
>
>미리 보기: 2026년 9월 3일
>프로덕션 빠른 릴리스: 2026년 9월 17일
>모두를 위한 프로덕션: 2026년 10월 15일

이제 Workfront 내에서 CX Coworker 를 사용할 수 있습니다. 이제 Workfront 전체에서 사용할 수 있는 패널에서 CX Coworker에 액세스할 수 있습니다.

CX Coworker Chat 은 작업 완료를 위한 대화 인터페이스입니다. 목표를 일반 언어로 설명하면, 동료가 작업을 계획하고, Workfront 및 연결된 Adobe 시스템에서 작업을 실행하고, 결과를 확인한 다음 완료된 작업을 다시 사용자에게 제출하여 승인을 받습니다.

동료는 기본적으로 읽기 전용 액세스 권한을 가진 조직의 기존 액세스 제어를 준수하며 시스템 관리자는 사용자가 쓰기 액세스 권한을 받을 때 제어합니다.

동료는 작업을 완료할 수 있는 보다 강력한 방법으로 현재 AI Assistant를 대체하고 있습니다. 동료는 Adobe 생태계의 일부이며 Workfront에 국한되지 않습니다.

>[!IMPORTANT]
>
>CX Coworker 는 현재 의료 서비스, 금융 기관 또는 중요한 데이터가 있는 기타 업계 조직에서 사용할 수 없습니다. 이러한 조직에서는 AI Assistant를 사용할 수 있습니다.

자세한 내용은 [CX Coworker 개요](/help/quicksilver/workfront-basics/coworker-in-workfront/coworker-overview.md)를 참조하십시오.

## Workfront MCP 커넥터에서 사용할 수 있는 새로운 검색 사용자 도구

>[!NOTE]
>
>프로덕션: 2026년 8월 13일

Workfront 인스턴스에서 사람들을 더 빨리 찾을 수 있도록 Workfront MCP 커넥터에 새로운 도구를 추가했습니다.

* 사용자 검색

상위 일치하는 사용자를 다시 가져오려면 사용자 검색 도구에 전체 또는 일부 이름을 입력합니다. 결과에 일반 사용자와 함께 AI 공동 작업자 &quot;보트&quot;를 포함하도록 선택할 수도 있습니다.

이 변경 사항의 일부로, 다음 도구는 더 이상 사용되지 않습니다.

* 문서 찾기
* 프로젝트 찾기
* 이름으로 팀 찾기
* 이름으로 사용자 찾기
* 현재 사용자 가져오기
* 범위별 문서 가져오기

이러한 도구를 사용하는 워크플로가 있는 경우 이름으로 ID 찾기, Workfront 데이터 찾기 또는 사용자 검색 도구를 대신 사용하도록 업데이트하십시오.

자세한 내용은 [Adobe Workfront MCP 서버 도구](/help/quicksilver/workfront-basics/workfront-mcp-server/workfront-mcp-server-tools.md)를 참조하십시오.

## Workfront MCP 서버를 사용하여 Adobe Experience Manager에 에셋을 전송하고 승인을 위해 사용자 지정 메시지를 추가합니다.

>[!NOTE]
>
>미리 보기: 2026년 8월 12일
>프로덕션: 2026년 8월 12일

Workfront MCP 커넥터의 기능을 확장하기 위해 다음과 같은 도구를 추가했습니다.

* AEM 연결 폴더로 문서를 보내고 프로젝트에서 사용할 수 있는 AEM 연결 폴더를 나열합니다.
* 제목, 승인자 또는 검토자, 선택적 기한과 함께 사용자 정의 메시지가 있는 문서 버전에 대한 승인을 요청합니다.

자세한 내용은 [Adobe Workfront MCP 서버 도구](/help/quicksilver/workfront-basics/workfront-mcp-server/workfront-mcp-server-tools.md)를 참조하십시오.

## Workfront의 작업에 AI 작업 공동 작업자 할당

>[!NOTE]
>
>미리 보기: 2026년 7월 31일
>프로덕션 빠른 릴리스: 2026년 8월 13일
>모두를 위한 프로덕션: 2026년 8월 13일

AI 에이전트를 사용하여 Workfront에서 작업을 수행할 수 있도록 작업 공동 작업자를 만들었습니다. 작업 공동 작업자는 문서 및 에셋 검토에 사용되는 기존 검토자 유형의 AI 공동 작업자 외에도 Workfront 작업에 직접 할당할 수 있는 AI 공동 작업자입니다. 작업 공동 작업자는 Copilot Studio, Claude 또는 Writer에서 구성한 에이전트에 연결하여 사용자를 지정하는 것처럼 작업에 할당합니다.

자세한 내용은 [AI 공동 작업자 구성](/help/quicksilver/administration-and-setup/set-up-workfront/configure-system-defaults/configure-ai-collaborators.md)을 참조하십시오.

## Workfront MCP 커넥터에서 사용할 수 있는 새로운 승인 도구

>[!NOTE]
>
>미리 보기: 2026년 7월 30일
>프로덕션 빠른 릴리스: 2026년 8월 13일

* 승인에서 경로 제거
* 경로에 단계 추가
* 경로에서 단계 제거
* 경로에서 단계 재정렬

또한 다음 도구가 병렬 승인 경로를 수용하도록 확장되었습니다.

* 승인 워크플로 정보 가져오기
* 승인 워크플로우 만들기 또는 업데이트
* 템플릿에서 승인 만들기
