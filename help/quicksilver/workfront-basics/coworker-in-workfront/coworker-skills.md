# CX 동료 기술

{{preview-fast-release-general}}

>[!IMPORTANT]
>
>CX Coworker 는 현재 의료 서비스, 금융 기관 또는 중요한 데이터가 있는 기타 업계 조직에서 사용할 수 없습니다. 이러한 조직에서는 AI Assistant를 사용할 수 있습니다. 자세한 내용은 [AI Assistant 개요](/help/quicksilver/workfront-basics/ai-assistant/ai-assistant-overview.md)를 참조하십시오.

이 문서에서는 Workfront의 CX Coworker가 현재 사용할 수 있는 스킬을 나열합니다.

이러한 기술이 다루는 기능은 대화 인터페이스를 통해 CX Coworker에서 사용할 수 있으며 이러한 기술을 직접 호출할 필요는 없습니다. 그러나 스킬을 직접 호출하려면 슬래시 `/`을(를) 입력하고 스킬의 이름을 입력하여 [동료] 패널에서 호출할 수 있습니다.

예를 들어 프롬프트는 문서 [Adobe Workfront MCP 서버 사용](/help/quicksilver/workfront-basics/workfront-mcp-server/use-workfront-mcp-server.md)에서 프롬프트를 참조하십시오.

## Workfront 계획 기술

### Workfront Planning 솔루션 설계자

이름: `wf-planning-solution-architect`

이 스킬은 다음을 포함하되 이에 제한되지 않는 Workfront Planning과 관련된 질문에 답변할 수 있습니다.

* Workspace 디자인
* 공식 필드 구문
* API 필터링
* 레코드 연결
* 자동화 옵션
* 보고
* 액세스 및 권한
* 통합
* 가격 책정 계층별 제품 제한

### Workfront 계획 관리

이름: `manage-workfront-planning`

이 스킬은 다음과 같은 Workfront Planning 객체를 쿼리하고 관리합니다.

* 작업 영역
* 섹션
* 레코드 유형
* 필드
* 보기 횟수
* 레코드

### Workfront 개체 관리

이름: `manage-workfront-objects`

이 스킬은 Workfront 프로젝트, 작업, 문제, 포트폴리오 및 프로그램을 만들고 업데이트합니다. 예로는 다음이 있습니다.

* 프로젝트 만들기
* 작업 추가
* 계획된 일자 설정
* 작업 할당

### Workfront 데이터 쿼리

이름: `query-workfront-data`

이 스킬은 다음과 같은 Workfront 개체를 찾아 나열하고 보고합니다.

* 프로젝트
* 작업
* 문제
* 사용자
* 포트폴리오
* 외
