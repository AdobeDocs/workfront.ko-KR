<!--Audited: 04/2024-->

Adobe Workfront은 [!UICONTROL 업데이트] 섹션의 특정 개체에 대해 수행되는 활동을 시스템 업데이트로 자동으로 기록합니다. 시스템 업데이트에는 객체에 발생한 변경 사항을 설명하는 간단한 메모가 포함되어 있습니다. [!DNL Workfront] 관리자는 [!UICONTROL 업데이트] 섹션에서 시스템이 추적할 변경 유형을 정의할 수 있습니다.
