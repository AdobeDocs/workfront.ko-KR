# Adobe Creative Cloud 프로젝트 개요

Adobe Photoshop, Illustrator 및 InDesign에서 직접 Workfront 프로젝트에 액세스할 수 있습니다. Creative Cloud 앱 창의 왼쪽에 있는 프로젝트 패널에서 앱을 종료하지 않고 Workfront 프로젝트에서 문서를 열고, 편집하고, 저장할 수 있습니다. 새 파일을 Workfront 프로젝트에 직접 저장할 수도 있습니다.

Adobe 클라우드 스토리지를 사용하는 프로젝트만 다른 Creative Cloud 프로젝트와 함께 프로젝트 패널에 표시됩니다. 패널은 Workfront 문서의 폴더 구조를 미러링합니다.

승인 워크플로가 있는 문서를 저장하면 Workfront에서 새 버전을 만들고 승인 기록을 유지합니다. 승인 워크플로가 없는 문서를 저장하면 Workfront에서 최신 버전을 업데이트합니다.

## 전제 조건

* 조직은 Adobe 클라우드 스토리지를 지원하는 Workfront 버전을 사용해야 합니다.
* Workfront 및 Photoshop, Illustrator 또는 InDesign은 동일한 Adobe IMS(Identity Management System) 조직에서 권한을 부여받아야 합니다.


## Photoshop, Illustrator 또는 InDesign의 프로젝트 패널에서 수행할 수 있는 작업

* Photoshop, Illustrator 또는 InDesign에서 직접 Workfront 프로젝트 폴더 및 문서를 엽니다. 액세스 권한이 있는 모든 Workfront 프로젝트가 [프로젝트] 패널에 표시됩니다.
* 파일을 편집하고 변경 사항을 다시 Workfront 프로젝트에 저장합니다.

자세한 내용은 [Creative Cloud 앱에서 Workfront 문서 사용](/help/quicksilver/documents/adobe-creative-cloud-projects/use-wf-documents-in-cc-apps.md)을 참조하십시오.

>[!NOTE]
>
>레거시 Workfront 스토리지 프로젝트는 프로젝트 패널에서 지원되지 않습니다.

## 관련 통합

또한 Adobe Cloud Drive를 사용하여 Workfront 파일을 관리하고 Workfront의 문서에 대한 변경 사항을 자동으로 저장할 수 있습니다. 자세한 내용은 [Adobe Cloud Drive 개요](/help/quicksilver/documents/adobe-cloud-drive/adobe-cloud-drive-overview.md)를 참조하세요.
