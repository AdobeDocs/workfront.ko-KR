# Adobe 클라우드 드라이브 사용

Adobe Cloud Drive를 설치한 후에는 Finder 또는 파일 탐색기에서 직접 Adobe 클라우드 스토리지 프로젝트로 작업할 수 있습니다. 모든 애플리케이션에서 파일을 열고 편집하고, 오프라인으로 작업하고, Adobe Cloud Drive에서 변경 사항을 클라우드에 동기화하도록 할 수 있습니다.

Adobe Cloud Drive 설치에 대한 자세한 내용은 [Adobe Cloud Drive 설치](/help/quicksilver/documents/adobe-cloud-drive/install-adobe-cloud-drive.md)를 참조하세요.

## 프로젝트 액세스

1. Finder(Mac) 또는 파일 탐색기(Windows)를 엽니다.
1. **Adobe 클라우드 드라이브**(으)로 이동합니다.
1. Workfront에서 액세스할 수 있는 프로젝트 목록을 검색합니다. 프로젝트 폴더를 열어 해당 파일 및 하위 폴더를 봅니다.

   >[!NOTE]
   >
   >* 프로젝트 폴더는 최상위 수준에서 읽기 전용입니다. 프로젝트 폴더 자체는 이름을 바꾸거나, 삭제하거나, 이동할 수 없습니다.
   >* 프로젝트 폴더 내의 파일 및 폴더(열기, 편집, 생성, 삭제 등)로 작업할 수 있습니다.
   >* 레거시 Workfront 프로젝트는 Adobe Cloud Drive에 표시되지 않습니다. Adobe 클라우드 저장소에 저장된 프로젝트만 사용할 수 있습니다.

### 오류 툴팁

동기화 오류 또는 문제가 발생하면 파일 또는 폴더 아이콘 위로 마우스를 가져가 문제를 설명하는 도구 설명을 확인합니다.

| 오류 범주 | 툴팁 | 의미 |
|---|---|---|
| 동기화가 제외됨 | 지원되지 않는 파일 유형 | Adobe Cloud Drive에서 파일 형식을 지원하지 않습니다. |
| 동기화가 제외됨 | 지원되지 않는 파일 이름 | Adobe Cloud Drive에서 파일 이름을 지원하지 않습니다. |
| 동기화가 제외됨 | 상위 프로젝트 삭제됨 | 상위 Workfront 프로젝트가 삭제되었습니다. |
| 동기화 일시 중단됨 | 지원되지 않는 파일 콘텐츠 | 파일 콘텐츠를 동기화할 수 없습니다(예: 보안 문제가 감지됨). |
| 동기화 일시 중단됨 | 파일 이름에 잘못된 문자가 있습니다 | 파일 이름에 잘못된 문자가 있습니다. |
| 동기화 일시 중단됨 | 전체 경로가 너무 깁니다. | 파일 경로가 허용된 최대 길이를 초과합니다. |
| 동기화 일시 중단됨 | 쓰기 권한 없음 | 이 파일 또는 프로젝트에 대한 쓰기 권한이 취소되었습니다. |
| 동기화 오류 | 인증 문제 | 로그인 자격 증명에 문제가 있습니다. |
| 동기화 오류 | 클라우드 스토리지를 사용할 수 없음 | Adobe 클라우드 서비스를 일시적으로 사용할 수 없습니다. |
| 동기화 오류 | 클라우드 스토리지 가득 참 | 클라우드 스토리지 할당량이 꽉 찼습니다. |
| 동기화 오류 | 로컬 디스크가 꽉 참 | 로컬 디스크에 사용 가능한 공간이 부족합니다. |
| 동기화 오류 | 인터넷 연결 없음 | 장치가 인터넷에 연결되어 있지 않습니다. |
| 동기화 오류 | 예기치 않은 오류 | 동기화하는 동안 예기치 않은 오류가 발생했습니다. |
| 동기화 오류 | 계정 차단됨 | 서비스에 의해 계정이 차단되었습니다. |

>[!NOTE]
>
>연결 해제, 인증 실패, 네트워크를 사용할 수 없음, 로컬 디스크 가득 참 또는 클라우드 저장소 가득 참 등의 시스템 수준 오류는 개별 파일이 아닌 시스템 트레이(Windows) 또는 메뉴 모음(Mac)에 표시됩니다.

### 동기화 제외 목록

Adobe Cloud Drive에서는 특정 시스템 생성, 임시 및 잠금 파일을 동기화에서 제외합니다. 다음 파일 형식 및 패턴은 제외됩니다.

| 범주 | 파일 유형 / 패턴 | 설명 |
|---|---|---|
| 시스템 파일 | `.DS_Store`, `Thumbs.db` | 운영 체제 메타데이터 및 썸네일 캐시 파일. |
| 시스템 및 가상 메모리 파일 | `*.sys`(예: `hiberfil.sys`, `pagefile.sys`, `swapfile.sys`) | 가상 메모리, 최대 절전 모드 또는 기타 운영 체제 기능에 사용되는 대용량 시스템 파일입니다. |
| macOS 색인화 파일 | `.Spotlight-V100`, `.fseventsd` | macOS Spotlight 색인 지정 및 파일 시스템 이벤트 추적 파일. |
| 임시 및 백업 파일 | `*.tmp`, `*.swp`, `*~`, `*.bak` | 애플리케이션에서 생성된 임시, 임시 또는 백업 파일. |

## 파일 열기

1. Adobe Cloud Drive에서 파일로 이동합니다.
1. 파일을 두 번 클릭합니다.

   기본 응용 프로그램에서 파일이 열립니다.

Adobe Cloud Drive는 다음을 포함하여 컴퓨터에 설치된 응용 프로그램이 열 수 있는 모든 파일 형식을 지원합니다.

* Adobe Creative Cloud 형식(PSD, AI, INDD, PRPROJ, AEP 등)
* Microsoft Office 문서(DOCX, XLSX, PPTX)
* 이미지(JPG, PNG, GIF 등)
* 비디오 파일(MP4, MOV 등)

>[!NOTE]
>
>클라우드 문서 형식(PSDC, AIDC 등)은 Adobe Cloud Drive를 통해 액세스할 때 표준 등가물(PSD, AI 등)로 열립니다.

## 파일 편집 및 저장

1. Adobe Cloud Drive에서 파일을 엽니다.
1. 응용 프로그램에서 변경 작업을 수행합니다.
1. **파일** > **저장**&#x200B;을 선택하거나 Ctrl+S(Windows) 또는 Cmd+S(Mac)를 눌러 파일을 저장합니다.

   변경 사항이 Adobe 클라우드 스토리지에 자동으로 동기화됩니다.

>[!IMPORTANT]
>
>**파일** > **저장** 또는 바로 가기 키를 사용하여 파일을 저장합니다. 드라이브에 중복 파일이 생성되므로 **다른 이름으로 저장**&#x200B;을 사용하여 복사본을 만들지 마십시오.

## 새 파일 만들기 또는 추가

프로젝트에서 직접 새 파일을 만들거나 로컬 저장소에서 기존 파일을 추가할 수 있습니다.

### 응용 프로그램에서 새 파일 만들기

1. 파일을 만드는 데 사용할 응용 프로그램을 엽니다.
1. 평소대로 파일을 만듭니다.
1. 저장할 때 Adobe Cloud Drive 프로젝트 폴더 내의 위치를 선택합니다.

   파일이 Adobe Cloud Drive에 나타나고 Adobe 클라우드 저장소에 동기화됩니다.

### 프로젝트에 기존 파일 추가

1. Finder(Mac) 또는 파일 탐색기(Windows)에서 Adobe Cloud Drive의 프로젝트 폴더를 엽니다.
1. 로컬 저장소에서 프로젝트 폴더로 파일을 끌거나 복사합니다.

   파일은 Adobe 클라우드 스토리지에 자동으로 동기화됩니다.

## 파일 및 폴더를 오프라인에서 사용 가능하도록 설정

파일 또는 폴더를 오프라인에서 사용할 수 있는 경우 인터넷 연결 없이 열고 편집할 수 있습니다. 오프라인 파일은 로컬 디스크 공간을 사용합니다.

### 장치에 파일 또는 폴더 보관

1. Adobe Cloud Drive의 파일 또는 폴더를 마우스 오른쪽 단추로 클릭합니다.
1. **이 장치에서 항상 유지**&#x200B;를 선택합니다.

   파일 또는 폴더가 로컬 캐시에 다운로드되므로 오프라인 상태에서도 로컬 캐시로 작업할 수 있습니다.

### 오프라인 액세스를 제거하여 공간을 확보하십시오.

1. 오프라인 파일 또는 폴더를 마우스 오른쪽 단추로 클릭합니다.
1. **사용 가능한 공간**&#x200B;을 선택하세요.

   파일 또는 폴더가 클라우드 저장소에 남아 있지만 로컬 캐시에서 제거됩니다.

>[!NOTE]
>
>오프라인 파일 및 폴더는 로컬 디스크 공간을 사용합니다. 더 이상 공간을 확보할 필요가 없는 파일 및 폴더에 대한 오프라인 액세스를 제거합니다.

## 로컬 저장소에 파일 복사

Adobe Cloud Drive의 파일을 로컬 드라이브에 복사할 수 있습니다. 원본은 Adobe Cloud Drive에 남아 있으며 복사본은 독립 로컬 파일이 됩니다.

1. Adobe Cloud Drive에서 파일을 마우스 오른쪽 단추로 클릭합니다.
1. **복사**&#x200B;를 선택한 다음 파일을 원하는 로컬 드라이브의 위치에 붙여넣습니다.

   파일이 대상에 복사됩니다. 원본은 Adobe Cloud Drive에 유지됩니다.

>[!NOTE]
>
>로컬 저장소에 복사된 파일은 독립 복사본입니다. 로컬 사본에 적용한 변경 사항은 Adobe 클라우드 스토리지에 다시 동기화되지 않습니다.

## 클라우드에 파일 업로드(직접 업로드) {#direct-upload}

<!-- Courtney check me: Source PDF calls this "Upload to Cloud (Direct Upload)". Confirm heading wording. -->

직접 업로드 는 먼저 Adobe Cloud Drive 폴더에 파일을 복사하지 않고 컴퓨터에서 Adobe 클라우드 저장소로 직접 파일을 보냅니다.

### 파일 업로드

1. Finder(Mac) 또는 File Explorer(Windows)에서 파일을 마우스 오른쪽 버튼으로 클릭합니다.
1. **클라우드에 업로드**&#x200B;를 선택합니다.
1. 대상 선택기에서 Adobe Cloud Drive의 프로젝트 중 하나 내의 위치를 선택한 다음 **여기에 업로드**&#x200B;를 클릭합니다.
1. 동기화 활동 창의 **직접 업로드** 섹션에서 진행 상황을 모니터링합니다.

### 직접 업로드에 대해 알아야 할 사항

* 직접 업로드 는 항목을 클라우드에 복사합니다. 원본 항목은 현재 위치에 남아 있습니다.
* 한 번에 업로드할 여러 항목을 선택할 수 있습니다.
* 직접 업로드 섹션에는 개별 파일만 나열됩니다(최대 500개).
* 사용자 홈 디렉토리 또는 연결된 외부 드라이브에서 항목을 업로드할 수 있습니다. iCloud Drive 또는 `~/Library/CloudStorage`과(와) 같은 다른 클라우드 저장소 위치는 지원되지 않습니다.
* 권한이 있는 Adobe 계정으로 로그인해야 합니다. 업로드를 시작하려면 인터넷에 연결할 필요가 없습니다. 연결이 없으면 업로드가 대기 중인 상태로 유지됩니다.
* 동기화를 일시 중지하면 진행 중인 업로드가 취소됩니다. 동기화를 다시 시작하면 대기 중인 업로드가 자동으로 다시 시작됩니다.
* 업로드 중에 Adobe 클라우드 드라이브를 종료하면 진행 중인 업로드가 취소됨으로 표시됩니다. 대기 중인 업로드는 앱을 다시 시작할 때 자동으로 다시 시작됩니다.
* 숨겨진 파일, 심볼 링크 및 별칭은 지원되지 않습니다.
* Adobe Cloud Drive는 동시에 실행되는 업로드 수를 제어합니다. 나머지 업로드는 슬롯을 사용할 수 있을 때까지 큐에 남아 있습니다.
* 실패한 업로드를 포함한 실시간 업로드 카운트가 표시됩니다(예: &quot;3개 파일 업로드&quot;). 모든 업로드가 성공적으로 완료되면 카운트는 &quot;업로드된 파일 3개&quot;와 같은 요약으로 변경됩니다. 제거하려면 **취소**&#x200B;를 선택하십시오.

* **지우기:** 업로드가 대기열에 있거나 진행 중일 때 사용할 수 있습니다. 완료, 실패 및 취소된 항목을 모두 제거합니다. 이미 업로드된 로컬 파일 및 컨텐츠는 영향을 받지 않습니다.
* **자동 지우기:** 완료, 실패 및 취소된 항목은 마지막 업데이트 후 24시간 후에 자동으로 제거됩니다. 대기 중인 항목 및 진행 중인 항목은 자동으로 제거되지 않습니다.

## 동기화 일시 중지 및 다시 시작 {#pause-resume-sync}

느린 인터넷 연결 또는 유료 인터넷 연결과 같이 파일을 업로드하거나 다운로드하지 않으려는 경우 Adobe Cloud Drive를 일시 중지할 수 있습니다. 동기화가 일시 중지된 상태에서는 변경 사항이 클라우드로 전송되지 않고 클라우드의 변경 사항이 컴퓨터로 다운로드되지 않습니다. 동기화를 다시 시작할 때까지 일시 중지된 상태로 유지됩니다.

### 동기화 일시 중지

1. 시스템 트레이(Windows)나 메뉴 모음(Mac)에서 Adobe Cloud Drive 아이콘을 클릭합니다.
1. Adobe Cloud Drive 창의 오른쪽 위 모서리에 있는 **메뉴** 아이콘(≡)을 클릭합니다.
1. **동기화 일시 중지**&#x200B;를 선택합니다.

   >[!TIP]
   >
   >Adobe Cloud Drive 창을 연 상태에서 Ctrl+P(Windows) 또는 Command+P(Mac)를 누를 수도 있습니다.

   Adobe 클라우드 드라이브 창에 **동기화가 일시 중지됨**&#x200B;이 표시되고 **다시 시작할 때까지 파일이 동기화되지 않습니다**. Adobe 클라우드 드라이브 아이콘 위로 마우스를 가져가면 **Adobe 클라우드 드라이브(일시 중지됨)**&#x200B;가 표시됩니다.

>[!NOTE]
>
>일시 중지 동기화는 로그인하고 Adobe Cloud Drive가 연결된 경우에만 사용할 수 있습니다.

### 동기화 다시 시작

1. 시스템 트레이(Windows)나 메뉴 모음(Mac)에서 Adobe Cloud Drive 아이콘을 클릭합니다.
1. 다음 중 하나를 수행하십시오.

   * **다시 시작**&#x200B;을 클릭합니다.
   * **메뉴** 아이콘(≡)을 클릭한 다음 **동기화 다시 시작**&#x200B;을 선택합니다. 창을 연 상태에서 Ctrl+R(Windows) 또는 Command+R(Mac)을 누를 수도 있습니다.

   동기화가 일시 중지된 동안 변경한 사항을 포함하여 Adobe Cloud Drive가 다시 동기화를 시작합니다.

## 버전 내역 보기 및 관리 {#version-history}

Adobe Cloud Drive의 버전 기록을 사용하여 지원되는 파일의 저장된 클라우드 버전을 찾고, 버전 세부 사항 및 썸네일을 보고, 이전 버전으로 되돌릴 수 있습니다. 필요한 권한이 있는 경우 버전의 이름과 설명을 편집할 수도 있습니다.

### 버전 내역 보기

1. Finder 또는 파일 탐색기에서 Adobe Cloud Drive 폴더로 이동합니다.
1. 지원되는 파일을 선택하십시오.
1. 파일을 마우스 오른쪽 단추로 클릭하고 **버전 기록**&#x200B;을 선택합니다.
1. 사용 가능한 세부 정보 및 썸네일을 보려면 버전을 선택하십시오.

   파일에 이전 버전이 없으면 **이전 버전이 표시되지 않습니다**. 일부 파일 또는 버전에서는 썸네일을 사용할 수 없습니다.

### 버전 정보 편집

1. 파일에 대한 버전 기록을 엽니다.
1. 업데이트할 버전을 선택합니다.
1. 버전의 옵션 메뉴를 열고 **버전 정보 편집**&#x200B;을 선택합니다.
1. **버전 이름** 또는 **설명**&#x200B;을 입력하십시오.
1. **저장**&#x200B;을 선택합니다.

   버전 기록을 다시 열면 업데이트된 정보가 저장되고 나타납니다.

### 이전 버전으로 되돌리기

1. 파일에 대한 버전 기록을 엽니다.
1. 복원할 버전을 선택합니다.
1. 가능한 경우 **이 버전으로 되돌리기**&#x200B;를 선택합니다.
1. 동기화가 완료될 때까지 기다립니다.
1. 파일을 다시 열어 선택한 버전의 콘텐츠가 현재 상태인지 확인합니다.

## 동기화 활동 보기 {#sync-activity}

동기화 활동은 컴퓨터의 Adobe Cloud Drive 폴더와 Adobe 클라우드 저장소 간의 최근 활동을 보여줍니다. 업로드 및 다운로드를 모니터링하고, 완료된 변경 사항을 검토하고, 동기화할 수 없는 항목을 식별하는 데 사용합니다.

### 동기화 활동 보기

1. 메뉴 모음(Mac) 또는 시스템 트레이(Windows)에서 Adobe Cloud Drive 아이콘을 선택합니다.
1. 상태 요약 옆에 있는 화살표를 사용하여 동기화 활동 섹션을 확장합니다.
1. 나열된 항목과 해당 상태 표시기를 검토합니다. 전송 진행률, 완료된 작업 또는 오류 메시지를 보려면 상태 표시기에 마우스를 가져다 대십시오.
1. 항목 옆에 있는 추가 작업 메뉴를 선택하여 해당 항목에 사용할 수 있는 작업을 확인합니다.

### 동기화 활동에 대해 알아야 할 사항

* 일반 동기화는 업로드, 다운로드, 만들기, 이름 변경, 이동 및 삭제 등 Adobe 클라우드 드라이브 폴더를 통해 변경된 사항을 추적합니다.
* 일반 동기화 목록에는 최대 500개의 최근 항목이 포함되어 있습니다. 새 항목 또는 업데이트된 항목이 맨 위에 나타납니다. 목록이 제한에 도달함에 따라 이전 항목이 제거될 수 있습니다.
* 항목의 이름 또는 메타데이터를 확인하는 동안 항목에 **준비 중...**&#x200B;이(가) 처음 표시될 수 있습니다.
* 요약에는 현재 동기화 중인 항목 수가 표시됩니다. **동기화 완료**&#x200B;는 현재 활성 상태인 항목이 없음을 의미합니다. 이 요약을 모든 항목이 성공했음을 확인하는 것으로 간주하지 않고 실패한 항목 또는 제외된 항목의 목록을 검사합니다.
* 동기화에서 제외된 파일 및 폴더가 지원되지 않는 이름, 지원되지 않는 유형 또는 기타 제외 이유를 설명하는 오류와 함께 나타날 수 있습니다.
* 로그아웃하면 활동이 지워집니다. 이 목록은 영구 감사 기록이 아닌 활동 보기입니다.

## Workfront에서 항목 열기 {#open-in-workfront}

Workfront에서 열기 를 선택하면 Adobe Cloud Drive의 항목에서 브라우저의 Workfront에 있는 해당 위치로 이동합니다. 수동으로 검색하지 않고도 Workfront에서 클라우드 항목 작업을 계속하려면 이 도구를 사용하십시오.

### Finder 또는 파일 탐색기에서 항목 열기

1. Finder(Mac) 또는 파일 탐색기(Windows)에서 Adobe Cloud Drive 폴더를 엽니다.
1. Workfront 항목과 연결된 단일 파일 또는 폴더를 선택합니다.
1. 항목을 마우스 오른쪽 단추로 클릭하고 **Workfront에서 열기**&#x200B;를 선택합니다.

   브라우저가 해당 Workfront 위치를 엽니다. 메시지가 표시되면 해당 항목에 액세스할 수 있는 계정으로 로그인합니다.

### 동기화 활동에서 항목 열기

1. 메뉴 모음(Mac) 또는 시스템 트레이(Windows)에서 Adobe Cloud Drive 아이콘을 선택합니다.
1. 동기화 활동 섹션을 확장합니다.
1. 완료되고 삭제되지 않은 적절한 항목의 경우 추가 작업 메뉴를 열고 **Workfront에서 열기**&#x200B;를 선택합니다.
1. 직접 업로드를 통해 업로드한 파일의 경우 **직접 업로드** 섹션의 완료된 항목에서 동일한 작업을 사용하십시오.

### Workfront Open에 대해 알아야 할 사항

* 한 번에 한 항목만 선택합니다. Workfront에서 선택한 여러 항목을 열 수 없습니다.
* 파일 탐색기에서 Adobe Cloud Drive 폴더 외부의 항목과 드라이브 루트 자체에 대해 명령을 숨깁니다. 여러 항목을 선택하면 비활성화됩니다.
* 항목에는 해당 Workfront 위치가 있어야 합니다. 일부 폴더 또는 기타 항목은 Adobe Cloud Drive에 표시되더라도 Workfront 매핑이 없을 수 있습니다.
* 업로드를 완료하지 않은 새 로컬 항목에는 아직 Workfront 링크가 없을 수 있습니다. 업로드가 완료될 때까지 기다린 후 다시 시도하십시오.
* 일반 동기화 활동에서 작업은 적격한 완료된 항목에 대해서만 제공됩니다. 활성, 실패 또는 삭제된 항목에 대해서는 제공되지 않습니다.
* 직접 업로드에서는 작업이 대기 중, 업로드, 실패 또는 취소된 항목이 아닌 완료된 업로드에 대해 제공됩니다.
* Adobe Cloud Drive에 로그인해야 합니다. Workfront에서 브라우저에서 별도로 로그인하도록 요청할 수도 있으며 Workfront 권한이 계속 적용됩니다.
* 캐시되지 않은 링크를 검색하고 Workfront에 액세스하려면 인터넷 연결이 필요합니다. 이전에 해결한 링크는 Workfront에 대한 오프라인 액세스를 제공하지 않습니다.
* 이 작업은 브라우저에서 Workfront을 엽니다. 데스크탑 애플리케이션에서 파일을 열지 않고, 다른 복사본을 업로드하거나, 로컬 오프라인 가용성을 변경하지 않습니다.

### Workfront에서 열기

| 항목 또는 상태 | Workfront에서 열기 비헤이비어 | 할 일 |
| --- | --- | --- |
| Adobe Cloud Drive의 단일 대상 항목 | 해당 Workfront 위치를 엽니다. | **Workfront에서 열기**&#x200B;를 선택합니다. |
| 여러 개의 선택한 항목 | 여러 항목을 열 수 없습니다. 파일 탐색기에서 명령을 사용할 수 없습니다. | 단일 항목을 선택합니다. |
| 새 항목 업로드 중 | Workfront 링크를 아직 사용하지 못할 수 있습니다. | 업로드가 완료될 때까지 기다린 후 다시 시도하십시오. |
| 완료된 정상 동기화 항목 | 항목이 적격하고 삭제되지 않은 경우 사용할 수 있습니다. | 항목의 추가 작업 메뉴를 사용합니다. |
| 완료된 직접 업로드 항목 | 업로드가 완료된 후 사용할 수 있습니다. | 항목의 추가 작업 메뉴를 사용합니다. |
| Workfront 매핑이 없는 항목 | Workfront에서 항목을 사용할 수 없다는 메시지가 표시됩니다. | Workfront에서 항목을 직접 확인하거나 다른 지원 항목을 선택하십시오. |
| 일반 동기화 항목 삭제됨 | 작업을 사용할 수 없습니다. | 삭제된 항목을 조사해야 하는 경우 Workfront을 직접 사용합니다. |

## Adobe 클라우드 드라이브에서 로그아웃

Adobe Cloud Drive에서 로그아웃해도 드라이브는 Finder 또는 파일 탐색기에 계속 표시됩니다. 그러나 로그아웃하는 동안 드라이브 내에서 변경한 사항과 로그아웃 전에 동기화되지 않은 변경 사항은 클라우드와 동기화하지 마십시오.

다음에 발생하는 일은 다시 로그인하는 계정에 따라 다릅니다.

### 동일한 계정으로 다시 로그인

Adobe Cloud Drive는 로그아웃할 때 로컬 탑재 폴더를 유지합니다. 동일한 자격 증명으로 다시 로그인하는 경우:

* Adobe Cloud Drive는 기존 마운트를 자동으로 재사용합니다.
* 로그아웃 전에 수행한 동기화되지 않은 변경 사항은 유지되며 연결이 복원되면 동기화됩니다.
* 사용자의 작업은 필요하지 않습니다.

### 다른 계정으로 로그인

로그아웃한 후 다른 Adobe 계정으로 로그인하는 경우:

* 현재 마운트된 폴더의 이름이 자동으로 변경되고 백업됩니다. 백업 폴더 이름은 `Adobe Cloud Drive <usermail>_<short_guid> (backup yyyy-MM-dd HH-mm-ss)` 형식을 사용합니다.
* 새 계정에 매핑된 Adobe 클라우드 드라이브는 Finder 또는 파일 탐색기에서 평소대로 사용할 수 있습니다.
* 백업 폴더를 제거하기 전에 동기화되지 않은 모든 작업을 수동으로 복구할 수 있습니다.

>[!NOTE]
>
>백업 폴더는 Mac의 `~/Library/CloudStorage` 및 Windows의 `C:\Users\<user>\`에 저장됩니다. 계정을 여러 번 전환하면 여러 개의 타임스탬프가 지정된 백업 폴더가 만들어집니다. 정기적으로 백업을 검토하고 정리하여 디스크 공간을 확보합니다.

## 파일 충돌 해결

충돌은 다음 상황 중 하나에서 발생할 수 있습니다.

* 여러 사용자가 동일한 파일을 동시에 편집하거나 삭제합니다.
* 다른 사용자가 파일을 여는 동안 파일이 수정됩니다.
* 네트워크 중단으로 인해 동기화 문제가 발생합니다.

### Adobe Cloud Drive로 충돌을 해결하는 방법

Adobe Cloud Drive는 충돌에 대해 복제 전략을 사용합니다.

* **파일 잠금이 없습니다.** 여러 사용자가 동시에 파일을 편집할 수 있습니다.
* **자동 복제** Adobe Cloud Drive에서 충돌을 감지하면 두 버전을 모두 유지합니다.
* **명명 지우기** 충돌 파일에는 사용자 이름과 타임스탬프가 `filename (Conflicted copy from username on date_time).extension` 형식으로 포함되어 있습니다. 예: `hero-banner (Conflicted copy from John on 2026-02-10_16-06-44).psd`.

### 수동으로 충돌 해결

1. 충돌 파일을 식별합니다. 충돌 파일의 파일 이름에 &quot;충돌하는 복사본&quot;이 있습니다.
1. 두 버전을 모두 검토하여 올바른 버전을 확인하십시오.
1. 올바른 버전을 유지하고 다른 버전을 삭제합니다.
1. 보존된 파일에 적절한 이름을 지정합니다.

>[!TIP]
>
>충돌을 최소화하려면
>
>* 파일을 편집하기 전에 동기화 상태를 확인하십시오.
>* 팀 구성원과 누가 어떤 파일을 편집하고 있는지에 대해 의견을 교환합니다.
>* 변경 사항이 신속하게 동기화되도록 자주 저장합니다.
>* 편집을 마치면 파일을 닫습니다.
