# Adobe Workfront Planning 릴리스 활동에 대한 관념화 공간

<span class="preview">이 페이지의 정보는 아직 일반적으로 사용할 수 없는 기능을 참조합니다. **관념화 공간 Beta** 프로그램의 일부로서만 사용할 수 있습니다. </span>

<span class="preview">자세한 내용은 [Adobe Workfront Planning의 Ideation 공간 시작](/help/quicksilver/planning/ideation/get-started-with-planning-ideation.md)을 참조하십시오.</span>

이 문서에서는 **관념화 공간 Beta** 기간 동안 Workfront Planning의 관념화 공간에 대해 릴리스되는 기능에 대해 설명합니다. Beta for Ideation 열기 공간은 2026년 11월 12일부터 2027년 2월 1일 사이에 실행될 예정입니다.

Adobe Workfront Planning 릴리스의 경우 [Adobe Workfront Planning 릴리스 활동: 문서 색인](/help/quicksilver/product-announcements/product-releases/planning-release-activity/planning-release-activity-article-index.md)을 참조하십시오.

## Adobe Workfront Planning의 관념화 공간에 대한 새 홈 영역

>[!NOTE]
>
>Ideation space 베타 고객을 위한 미리보기 및 프로덕션 환경에서 사용 가능: 2026년 11월 25일

Workfront 와플 메뉴에서 관념화 공간에 액세스하면 이제 관념화 공간 홈 영역이 열립니다. 여기에서는 기존 캔버스를 다시 열거나 만들 수 있으므로 기존 캔버스로 이동하기 위해 더 이상 빈 캔버스로 시작할 필요가 없습니다. 홈(Home) 영역에는 최근 캔버스를 타일로 표시하고 화면 하단에 다른 모든 캔버스를 나열하며 검색 상자가 포함됩니다. 캔버스 내에서 작업할 때 새 홈 버튼을 사용하여 관념화 공간 홈 영역으로 돌아갑니다.

자세한 내용은 [Ideation 공간에 브리프 만들기](/help/quicksilver/planning/ideation/create-briefs-in-ideation-space.md)를 참조하십시오.
